# SEO Blog Project — CLAUDE.md

## Опис проєкту

Двомовний (українська / англійська) SEO-блог про комп'ютери, комплектуючі, популярні ігри (ARC Raiders, DayZ та інші), порівняння продуктивності комплектуючих у сучасних іграх. Проєкт має подвійну мету: створити реальний блог для просування в Google та навчитися SEO-практикам на практиці.

## Стек технологій

- **Next.js** — фреймворк на базі React з серверним рендерингом (SSR) та статичною генерацією (SSG) для SEO
- **React** — бібліотека для побудови UI
- **TypeScript** — строга типізація для надійності коду
- Додаткові бібліотеки додаємо по мірі необхідності та обговорюємо перед додаванням

## Цільова аудиторія

- Геймери-новачки, які шукають поради що купити
- Досвідчені ентузіасти, яким цікаві детальні бенчмарки та порівняння
- Контент повинен бути доступним для обох груп

## Мови (i18n)

- Українська (основна) та англійська
- Кожна сторінка повинна мати версію обома мовами
- URL-структура з мовним префіксом: `/uk/...`, `/en/...`

## SEO-вимоги

- Кожна SEO-практика, інструмент чи рішення **обов'язково пояснюється** коментарем або в розмові — що це, навіщо, як працює
- Семантичний HTML: правильне використання `<header>`, `<main>`, `<article>`, `<section>`, `<nav>`, `<h1>`-`<h6>`
- Мета-теги: `title`, `description`, Open Graph, Twitter Cards
- Structured Data (JSON-LD) для статей
- Оптимізація зображень (alt-теги, формати, lazy loading)
- Sitemap та robots.txt створюємо окремо, коли перейдемо до етапу просування в Google

## Стиль коду

- Код повинен бути зрозумілим і читабельним
- Коментарі обов'язкові у великих компонентах та сторінках — пояснювати логіку та SEO-рішення
- Назви компонентів, змінних та функцій — англійською мовою
- Контент (тексти статей, UI-тексти) — українською та англійською через i18n

## Навчальний підхід

- Це навчальний проєкт: автор вивчає SEO та Next.js
- При використанні будь-якої SEO-техніки — пояснювати:
  1. **Що** це за практика
  2. **Навіщо** вона потрібна
  3. **Як** вона впливає на ранжування в Google
- При використанні Next.js-специфічних можливостей — пояснювати як вони працюють і чим відрізняються від звичайного React
